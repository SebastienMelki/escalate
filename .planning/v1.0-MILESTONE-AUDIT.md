## Gap Detail

### Gap 1: INTL-05 — Session Summary Never Sends (UNSATISFIED)

**Requirement:** "Session summary DM on TaskCompleted or Stop — phases completed, decisions made, notable events"

**Root cause:** `scripts/on-task-completed.ts:14-15`:
```ts
void requestSummary(port).catch(() => {});
process.exit(0);
```

`process.exit()` forcefully terminates Node.js without draining pending async I/O. The `fetch()` to `POST /summary` is killed before the TCP connection completes. Same pattern in `scripts/on-stop.ts:37-39`.

**Fix:** `await requestSummary(port)` before `process.exit(0)`, or use `setTimeout(() => process.exit(0), 500)` to allow the fetch to flush.

**Severity:** Medium. Core escalation loop unaffected. Only session summary feature is broken.

### Gap 2: SLCK-02 — Snooze Button Missing (PARTIAL)

**Requirement:** "Messages include interactive Approve/Deny/Snooze buttons for binary and multi-choice decisions"

**Root cause:** `buildActionsForEvent()` in `http-bridge.ts:80-100` returns only `[{id:'approve'}, {id:'deny'}]`. No event type generates a Snooze action. The Block Kit builder fully supports Snooze (tested at `blocks.test.ts:177`), but integration never produces one.

**Fix:** Add `{ id: 'snooze', label: 'Snooze' }` to actions and handle in output-helpers, OR update requirement to "Approve/Deny" if Snooze was intentionally dropped (timeout mechanism provides equivalent functionality).

**Severity:** Low. Approve/Deny works. Timeout serves as implicit snooze.

### Gap 3: SLCK-03 — File Paths Not in Slack Messages (PARTIAL)

**Requirement:** "Messages include rich GSD context — current phase, task name, what Claude was about to do, and why it needs a decision"

**Root cause:** `http-bridge.ts:293-296` constructs context with only `eventType` and `toolName`. The `filePaths` extracted at line 187 are used for rules and audit but not passed to the context object. `blocks.ts` has a dead "Files:" block branch.

**Fix:** Add `...(filePaths.length > 0 ? { filePaths } : {})` to the context object at line 293.

**Severity:** Low. Messages show event type and tool name. File paths are supplementary context.
