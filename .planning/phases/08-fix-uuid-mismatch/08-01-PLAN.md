<objective>
Fix the UUID mismatch bug (INT-01) where the HTTP bridge and Slack adapter generate independent UUIDs for the same escalation. Thread the store record ID through the EscalationRequest type so all Slack interactions (buttons, threads, emoji, voice) resolve the correct store record.

Purpose: Without this fix, the full escalation round-trip is broken -- hook scripts poll UUID-A while Slack resolves against UUID-B, causing every escalation to time out.

Output: A working end-to-end escalation loop where a single UUID flows from store creation through Slack dispatch to user interaction resolution.
</objective>
