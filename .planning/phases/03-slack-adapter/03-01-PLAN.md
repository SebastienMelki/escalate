  <action>
1. Install @slack/bolt as a runtime dependency:
   ```bash
   pnpm add @slack/bolt
   ```
   This bundles @slack/web-api, @slack/socket-mode, and @slack/types (TypeScript types included, no @types/ needed).

2. Create `src/slack/types.ts` with Slack-specific internal types:
   - `EscalationMessage` interface: `{ escalationId: string; channelId: string; ts: string; threadTs?: string }` -- maps an escalation to its Slack message coordinates
   - `ButtonStyle` type: `'primary' | 'danger' | undefined` -- maps SuggestedAction.style to Slack button styles
   - `SlackAdapterState` interface: `{ connected: boolean; escalationToTs: Map<string, string>; tsToEscalation: Map<string, string> }` -- ephemeral adapter state (not persisted to SQLite)

3. Create `src/slack/blocks.ts` with pure functions:

   **`buildEscalationBlocks(request: EscalationRequest, escalationId: string): KnownBlock[]`**
   Converts an EscalationRequest to Block Kit blocks:
   - `header` block: `request.title` as plain_text
   - `context` block: event type (always), tool name (if present) -- both as mrkdwn elements
   - `divider` block
   - `section` block: `request.question` as mrkdwn
   - `section` block (conditional): `request.context.taskContext` wrapped in blockquote `> ` if present
   - `context` block (conditional): `request.context.filePaths` joined with `, ` if non-empty array
   - `actions` block (conditional): buttons from `request.suggestedActions` if non-empty
     - Each button: `action_id: "escalate_{escalationId}_{action.id}"`, `value: action.id`
     - Style mapping: `'primary'` -> `{ style: 'primary' }`, `'danger'` -> `{ style: 'danger' }`, `'default'`/undefined -> no style property
     - text: `{ type: 'plain_text', text: action.label, emoji: true }`

   **`buildConfirmationBlocks(actionLabel: string, userId: string): KnownBlock[]`**
   Builds the replacement blocks after a button click:
   - `section` block with mrkdwn: `:white_check_mark: *{actionLabel}* by <@{userId}>`

   **`buildFallbackText(request: EscalationRequest): string`**
   Returns `"{request.title}: {request.question}"` -- used as the `text` field for notification fallback (non-Block-Kit clients).

   Import types from `@slack/types` (bundled with @slack/bolt): `KnownBlock`, `Button`.
   Import `EscalationRequest`, `SuggestedAction` from `../types/escalation.js`.

   IMPORTANT: Use `as const` or explicit type annotations on block objects to satisfy @slack/types' strict discriminated union types. The `type` field on each block must be a string literal, not `string`.
