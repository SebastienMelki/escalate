1. Create `src/slack/handlers.ts` with handler registration functions:

   **`registerActionHandler(app: App, adapter: SlackAdapterCallbacks): void`**
   Registers `app.action(/^escalate_/, ...)` listener:
   - Call `await ack()` IMMEDIATELY (first line -- Slack 3-second requirement)
   - Extract `action_id` from `(action as ButtonAction).action_id` (import ButtonAction from @slack/bolt)
   - Extract `ts` from `body.message?.ts`, `channelId` from `body.channel?.id`
   - Guard: if no ts or channelId, return early
   - Parse action_id format: `escalate_{escalationId}_{actionValue}` -- split on `_` to extract escalation ID and action value
   - Call `adapter.onAction(escalationId, actionValue, body.user.id)` callback
   - Call `client.chat.update()` to replace the original message with confirmation blocks (from `buildConfirmationBlocks`)
     - Keep the original header block from `body.message?.blocks?.[0]` if it exists
     - Add the confirmation section block after it

   **`registerMessageHandler(app: App, adapter: SlackAdapterCallbacks): void`**
   Registers `app.message(...)` listener:
   - Guard: if no `thread_ts` on message, return (not a thread reply)
   - Guard: if `bot_id` on message or `subtype === 'bot_message'`, return (bot's own message -- safety net alongside ignoreSelf)
   - Call `adapter.onThreadReply(message.thread_ts, message.text ?? '')` callback

   **`SlackAdapterCallbacks` interface:**
   ```typescript
   interface SlackAdapterCallbacks {
     onAction(escalationId: string, actionValue: string, userId: string): void;
     onThreadReply(threadTs: string, text: string): void;
   }
   ```
   Export this interface.

2. Create `src/slack/adapter.ts` with the SlackAdapter class:

   ```typescript
   import { App, LogLevel } from '@slack/bolt';
   ```

   **Constructor:** `constructor(options: SlackAdapterOptions)`
   ```typescript
   interface SlackAdapterOptions {
     botToken: string;
     appToken: string;
     channelId: string;
     store: EscalationStore;
   }
   ```
   - Create Bolt App with `socketMode: true`, `appToken`, `token: botToken`, `logLevel: LogLevel.ERROR` (CRITICAL: prevent stdout pollution of MCP stdio)
   - Store channelId and store reference
   - Initialize bidirectional maps: `escalationToTs` and `tsToEscalation` (both `Map<string, string>`)
   - Initialize `responseResolvers` map: `Map<string, (response: UserResponse) => void>`
   - Register handlers using `registerActionHandler` and `registerMessageHandler`, passing callback implementations

   **Callback implementations (private methods):**

   `private handleAction(escalationId: string, actionValue: string, _userId: string): void`
   - Look up escalation ID from `tsToEscalation` map (the handler already parsed the action_id)
   - Resolve in store: `this.store.resolve(escalationId, JSON.stringify({ type: 'action', actionId: actionValue }))`
   - If resolve returns false (already resolved -- race with thread reply), do nothing
   - If resolve returns true, check `responseResolvers` for a pending Promise resolver and call it with `{ type: 'action', actionId: actionValue, respondedAt: new Date() }`
   - Clean up maps: delete from `escalationToTs`, `tsToEscalation`, `responseResolvers`

   `private handleThreadReply(threadTs: string, text: string): void`
   - Look up escalation ID from `tsToEscalation` using threadTs
   - If no match, return (not a tracked thread)
   - Resolve in store: `this.store.resolve(escalationId, JSON.stringify({ type: 'text', text }))`
   - If resolve returns false, do nothing (already resolved)
   - If resolve returns true, check `responseResolvers` and call with `{ type: 'text', text, respondedAt: new Date() }`
   - Clean up maps

   **`async start(): Promise<void>`**
   - Call `await this.app.start()` -- connects Socket Mode WebSocket
   - Set `this.connected = true`
   - Log to stderr: `console.error('[escalate] Slack Socket Mode connected')`

   **`async stop(): Promise<void>`**
   - Call `await this.app.stop()`
   - Set `this.connected = false`

   **`async validateAndAnnounce(): Promise<void>`** (CFG-03)
   - Call `this.app.client.auth.test()` -- verify bot token
   - If `!result.ok`, throw Error with message: `Slack authentication failed. Check ESCALATE_SLACK_BOT_TOKEN. Error: ${result.error}`
   - Log to stderr: `[escalate] Authenticated as ${result.user} in workspace ${result.team}`
   - Call `this.app.client.chat.postMessage({ channel: this.channelId, text: ':zap: Escalate online -- ready to receive escalations' })`
   - If `!postResult.ok`, throw Error with message: `Failed to post to channel ${this.channelId}. Check channel ID and bot permissions. Error: ${postResult.error}`
   - Log to stderr: `[escalate] Posted startup message to channel ${this.channelId}`

   **`async sendEscalation(request: EscalationRequest): Promise<string>`**
   - Generate escalationId: `crypto.randomUUID()`
   - Build blocks: `buildEscalationBlocks(request, escalationId)`
   - Build fallback: `buildFallbackText(request)`
   - Call `this.app.client.chat.postMessage({ channel: this.channelId, blocks, text: fallbackText })`
   - Extract `ts` from result (assert non-null: `const ts = result.ts; if (!ts) throw new Error(...)`)
   - Store bidirectional mapping: `escalationToTs.set(escalationId, ts)`, `tsToEscalation.set(ts, escalationId)`
   - Return escalationId

   **`async waitForResponse(escalationId: string, timeoutMs: number): Promise<UserResponse>`**
   - Return a new Promise that:
     - Sets a timeout timer for `timeoutMs` -- on expiry, clean up resolver from map, resolve with `{ type: 'timeout', respondedAt: new Date() }`
     - Adds a resolver to `responseResolvers` map keyed by escalationId -- when called, clear timeout timer, resolve with the response

   **`async sendFollowUp(escalationId: string, message: string): Promise<void>`**
   - Look up `ts` from `escalationToTs` map
   - If no ts found, return silently (escalation not tracked or already cleaned up)
   - Call `this.app.client.chat.postMessage({ channel: this.channelId, thread_ts: ts, text: message })`

   **`isConnected(): boolean`**
   - Return `this.connected`

   - Add module-level variable: `let slackAdapter: SlackAdapter | undefined;`
   - In `startServer()`, AFTER the HTTP bridge starts and port file is written, add Slack adapter startup:

   ```typescript
   // Load config and secrets for Slack adapter
   const configResult = loadConfig();
   const secretsResult = loadSecrets();

   if (isOk(configResult) && isOk(secretsResult)) {
     const config = configResult.value;
     const secrets = secretsResult.value;

     slackAdapter = new SlackAdapter({
       botToken: secrets.slackBotToken,
       appToken: secrets.slackAppToken,
       channelId: config.slack.channelId,
       store,
     });

     try {
       await slackAdapter.start();
       await slackAdapter.validateAndAnnounce();
     } catch (error: unknown) {
       console.error('[escalate] Slack adapter failed to start:', error);
       // Don't crash the MCP server -- Slack is optional
       // Log the error but continue with MCP + HTTP bridge
       slackAdapter = undefined;
     }
   } else {
     console.error('[escalate] Slack adapter not started: missing config or secrets');
     if (!isOk(configResult)) {
       console.error('[escalate] Config error:', configResult.error.message);
     }
     if (!isOk(secretsResult)) {
       console.error('[escalate] Secrets error:', secretsResult.error.message);
     }
   }
   ```
