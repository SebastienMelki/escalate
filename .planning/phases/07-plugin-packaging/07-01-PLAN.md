  <action>
Migrate every file that imports better-sqlite3 to use the built-in node:sqlite module. Apply these changes systematically:

**Import changes:**
- `import type Database from 'better-sqlite3'` becomes `import type { DatabaseSync } from 'node:sqlite'`
- `import Database from 'better-sqlite3'` becomes `import { DatabaseSync } from 'node:sqlite'`
- `import type { Database as DatabaseType } from 'better-sqlite3'` becomes `import type { DatabaseSync } from 'node:sqlite'`

**Type changes in source files:**
- `Database.Database` becomes `DatabaseSync`
- `Database.Statement` becomes `StatementSync` (import from `node:sqlite`)
- `db: Database.Database` becomes `db: DatabaseSync`

**API changes in schema.ts:**
- `db.pragma('journal_mode = WAL')` becomes `db.exec('PRAGMA journal_mode = WAL')`
- `db.pragma('busy_timeout = 5000')` becomes `db.exec('PRAGMA busy_timeout = 5000')`
- `db.pragma('foreign_keys = ON')` becomes `db.exec('PRAGMA foreign_keys = ON')`

**Constructor change in server/index.ts:**
- `new Database(dbPath)` becomes `new DatabaseSync(dbPath)`

**Test file changes:**
- `new Database(':memory:')` becomes `new DatabaseSync(':memory:')`
- `db: Database.Database` becomes `db: DatabaseSync`
- All type references updated accordingly

**store.ts specific:**
- `result.changes > 0` -- node:sqlite's `result.changes` is `number | bigint`. Use `Number(result.changes) > 0` to handle both.
- Update JSDoc comments to reference node:sqlite instead of better-sqlite3.

**Package removal:**
- Run `pnpm remove better-sqlite3 @types/better-sqlite3`
- Remove `better-sqlite3` from `pnpm.onlyBuiltDependencies` array in package.json (keep `esbuild`)

After all changes, run `pnpm run typecheck` to verify TypeScript compilation passes.
