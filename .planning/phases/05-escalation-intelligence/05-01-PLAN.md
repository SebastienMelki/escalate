- `EvaluationInput` interface: `{ eventType: string; toolName?: string; filePaths?: readonly string[] }`

- `evaluateRules(input: EvaluationInput, rules: readonly AutoApprovalRule[], policy: 'always' | 'conditional' | 'never'): EvaluationResult` -- policy short-circuits first, then iterate rules checking tool_name patterns with RegExp and file_path patterns with globToRegex.

Run tests -- they MUST pass.

Use ESM `.js` extensions for imports. Follow existing codebase patterns: `readonly` on interface properties, explicit return types, no `any`.
