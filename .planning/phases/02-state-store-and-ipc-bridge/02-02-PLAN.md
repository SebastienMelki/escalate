  <action>
Create `src/server/mcp-server.ts` that exports a `createMcpServer(store: EscalationStore)` function.

**Implementation:**

Import `McpServer` from `@modelcontextprotocol/sdk/server/mcp.js` and `z` from `zod`.

`createMcpServer(store)` creates a `new McpServer({ name: 'escalate', version: '0.1.0' }, { capabilities: { tools: {} } })` and registers these tools:

1. **`create_escalation`**: Creates a pending escalation. Input schema (zod): `event_type: z.string()`, `title: z.string()`, `question: z.string()`, `urgency: z.enum(['info', 'warning', 'critical'])`, `context_json: z.string().optional()`, `fallback_action: z.enum(['allow', 'deny', 'ask-again']).default('deny')`, `timeout_seconds: z.number().default(600)`. Calls `store.create(...)` with `requestJson` as JSON.stringify of `{title, question, urgency, context_json}`. Returns `{ content: [{ type: 'text', text: JSON.stringify({ escalation_id: record.id, status: record.status }) }] }`.

2. **`get_escalation`**: Gets an escalation by ID. Input: `escalation_id: z.string()`. First calls `store.checkTimeout(id)` to handle expiry, then `store.getById(id)`. Returns the record as JSON text content. Returns error text if not found.

3. **`resolve_escalation`**: Resolves a pending escalation. Input: `escalation_id: z.string()`, `response_json: z.string()`. Calls `store.resolve(id, responseJson)`. Returns success/failure as JSON text content.

4. **`list_pending`**: Lists pending escalations. No input. Calls `store.getPending()`. Returns array as JSON text content.

Return the `McpServer` instance (do NOT connect transport here -- that happens in the entrypoint).

**CRITICAL:** Never use `console.log()` in this file. The MCP server uses stdio, so any stdout output corrupts the protocol. Use `console.error()` for debug logging if needed.

**HTTP Bridge (`src/server/http-bridge.ts`):**

Export `createHttpBridge(store: EscalationStore)` that returns an `http.Server`.

Routes:
- `GET /health` — returns `200 { status: 'ok' }`
- `POST /escalations` — parses JSON body with fields: `event_type`, `request_json`, `fallback_action` (default 'deny'), `timeout_seconds` (default 600). Calls `store.create(...)`. Returns `201 { escalation_id, status }`.
- `GET /escalations/:id` — extracts ID from URL path (parse `url.pathname.split('/')[2]`). First calls `store.checkTimeout(id)` to detect expiry. Then `store.getById(id)`. Returns `200` with the record JSON, or `404 { error: 'not found' }`.
- All other routes: `404 { error: 'not found' }`

Bind to `127.0.0.1` only (no external access). Use Node.js `http.createServer` with `IncomingMessage/ServerResponse`.

JSON body parsing: collect chunks, `Buffer.concat`, `JSON.parse`. Return 400 on invalid JSON.

Set `Content-Type: application/json` on all responses.

**Server Entrypoint (`src/server/index.ts`):**

Export `startServer(options?: { port?: number; dbPath?: string })` as an async function.

Implementation:
1. Determine `dbPath`: `options.dbPath ?? path.join(process.env['CLAUDE_PROJECT_DIR'] ?? process.cwd(), '.claude', 'escalate.db')`
2. Create `.claude/` directory with `mkdirSync(dirname(dbPath), { recursive: true })`
3. Open `better-sqlite3` database at `dbPath`
4. Create `EscalationStore` with the database
5. Create MCP server with `createMcpServer(store)`
6. Create HTTP bridge with `createHttpBridge(store)`
7. Start HTTP bridge: `httpServer.listen(options.port ?? 0, '127.0.0.1', callback)`
8. In listen callback: get bound port from `httpServer.address()`, write port to `portFilePath` = `path.join(process.env['CLAUDE_PROJECT_DIR'] ?? process.cwd(), '.claude', 'escalate-port')` using `writeFileSync`
9. Connect MCP server to stdio: `const transport = new StdioServerTransport(); await mcpServer.connect(transport);`
10. Log startup to stderr: `console.error('[escalate] MCP server started, HTTP bridge on port ${port}')`

Also export `stopServer()` for clean shutdown: close HTTP server, close database.

Handle process signals: `process.on('SIGTERM', ...)` and `process.on('SIGINT', ...)` to call `stopServer()`.
